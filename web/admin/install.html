Application Android

Téléchargez l'application officielle Orderflow pour vos serveurs. Elle offre une expérience plein écran, rapide et optimisée pour la prise de commande.

Télécharger l'APK
Important lors de l'installation : Comme cette application n'est pas sur le Play Store, Android affichera un message d'avertissement. Cliquez sur "Paramètres" puis cochez "Autoriser depuis cette source", et enfin sur "Installer quand même".
